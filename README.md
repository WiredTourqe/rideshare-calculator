# Advanced Rideshare Analytics

A comprehensive, postgraduate-level performance analysis and optimization platform for rideshare drivers.

## 🚀 Features

### Core Analytics
- **Comprehensive Metrics Dashboard** - 30+ calculated performance indicators
- **Advanced Statistical Analysis** - Confidence intervals, variance analysis, outlier detection
- **Performance Scoring System** - AI-driven scorecard with personalized recommendations
- **Interactive Data Visualization** - Charts, graphs, and real-time analytics

### Postgraduate-Level Functionality
- **Financial Analysis** - ROI calculations, profit margins, cost analysis
- **Predictive Analytics** - Earnings forecasting and trend analysis
- **Market Comparison** - Benchmark performance against industry averages
- **Optimization Strategies** - Data-driven recommendations for improvement

### Modern Technology Stack
- **React 19** with TypeScript for type-safe development
- **Vite** for blazing-fast build times and hot module replacement
- **Tailwind CSS** for modern, responsive design
- **Chart.js** for interactive data visualizations
- **Advanced Mathematical Functions** for statistical computations

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ 
- npm or yarn package manager

### Installation
```bash
# Clone the repository
git clone <repository-url>

# Navigate to project directory
cd rideshare-calculator

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

### Usage
1. **Data Input** - Enter your rideshare session data
2. **Metrics Dashboard** - Review comprehensive performance analytics
3. **Performance Score** - View your AI-generated performance scorecard
4. **Data Visualization** - Explore interactive charts and graphs
5. **Advanced Analytics** - Access market comparisons and optimization strategies
